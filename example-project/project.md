## Description

Complete modernization of HCI EPD system from ASP Classic/ASP.NET to .NET Core/Blazor. The project involves migrating 1.38M LOC of legacy code while maintaining compliance with NEN7510 and ISO27001 standards.

## Goals

- Modernize entire codebase to .NET Core/Blazor
- Achieve NEN7510 and ISO27001 compliance
- Improve system performance by 40%
- Enable cloud deployment capability
- Reduce technical debt by 60%

## Notes

Project started November 2025. Initial assessment phase shows significant technical debt but solid business logic foundation. Key challenges: legacy database schema, end-of-life third-party components (Telerik, MyGeneration).
