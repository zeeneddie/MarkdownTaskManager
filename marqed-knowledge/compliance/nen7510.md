# NEN 7510 Compliance Checklist

## Overview
NEN 7510 is the Dutch healthcare information security standard based on ISO 27001/27002.

## Key Requirements

### 1. Access Control
- [ ] Role-based access control (RBAC)
- [ ] Two-factor authentication for clinical staff
- [ ] Regular access rights review
- [ ] Automatic session timeout

### 2. Data Protection
- [ ] Patient data encrypted at rest (AES-256)
- [ ] Data encrypted in transit (TLS 1.2+)
- [ ] Secure key management
- [ ] Data masking in non-production

### 3. Audit Logging
- [ ] All PHI access logged
- [ ] Log retention (minimum 2 years)
- [ ] Tamper-proof audit trails
- [ ] Regular log review

### 4. Incident Management
- [ ] Incident response procedures
- [ ] Data breach notification process
- [ ] Regular incident drills
