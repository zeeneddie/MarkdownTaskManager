# Generated Code Detection & Exclusion Guide

**Version:** 1.0
**Last Updated:** January 2026

---

## Executive Summary

Gegenereerde code moet anders behandeld worden dan handgeschreven code:
- **WEL:** Security scans, volume metingen (LOC, files, folders)
- **NIET:** Kwaliteitsmetingen (complexity, duplication, maintainability)

Dit document beschrijft de detectiepatronen en implementatiestrategie.

## 1. Code Generator Types & Characteristics

### 1.1 Directory-Based Generators

| Generator Type | Directory Pattern | Tool | Language |
|----------------|-------------------|------|----------|
| VB.NET Settings/Resources | `My Project/` | VS IDE | VB.NET |
| WCF Service References | `Service References/` | svcutil.exe | .NET |
| ASMX Web References | `Web References/` | wsdl.exe | .NET |
| Connected Services | `Connected Services/` | VS 2017+ | .NET |
| Node Dependencies | `node_modules/` | npm/yarn | JS/TS |
| Go Vendor | `vendor/` | go mod | Go |
| Python Packages | `site-packages/`, `.venv/` | pip | Python |
| Build Output | `obj/`, `bin/`, `dist/`, `build/` | Various | All |
| Generated Folder | `Generated/`, `__generated__/` | Various | All |

### 1.2 File Pattern-Based Generators

| Generator Type | File Pattern | Tool | Purpose |
|----------------|--------------|------|---------|
| Windows Forms Designer | `*.Designer.vb`, `*.Designer.cs` | VS Designer | UI initialization |
| WPF Designer | `*.g.cs`, `*.g.vb` | VS XAML | XAML code-behind |
| Web Service Proxy | `Reference.vb`, `Reference.cs` | wsdl/svcutil | Service clients |
| Entity Framework | `*.edmx.cs`, `*.edmx.vb` | EF Designer | ORM models |
| T4 Templates | `*.generated.cs`, `*.tt.cs` | T4 Engine | Custom generation |
| Protocol Buffers | `*.pb.go`, `*.pb.cc`, `*_pb2.py` | protoc | Serialization |
| OpenAPI/Swagger | `*Api.cs`, `*Client.cs` | OpenAPI Gen | REST clients |
| GraphQL | `*.graphql.ts`, `*.generated.ts` | GraphQL Codegen | Query types |
| Thrift | `*_types.py`, `*_constants.py` | thrift | RPC |
| Lock Files | `*.lock`, `package-lock.json` | Package managers | Dependencies |
| Minified | `*.min.js`, `*.min.css` | Minifiers | Production assets |
| Bundled | `*.bundle.js`, `*.chunk.js` | Bundlers | Webpack/Rollup |

## 2. Industry Standard Tools & Configurations

### 2.1 GitHub Linguist

[GitHub Linguist](https://github.com/github-linguist/linguist) is the industry standard for detecting generated code.

**Key file:** [`generated.rb`](https://github.com/github/linguist/blob/master/lib/linguist/generated.rb)

**Configuration via `.gitattributes`:**
```gitattributes
# Directory exclusions
**/My\ Project/** linguist-generated=true
**/Service\ References/** linguist-generated=true
**/Web\ References/** linguist-generated=true
**/Connected\ Services/** linguist-generated=true
**/node_modules/** linguist-generated=true
**/vendor/** linguist-generated=true
**/obj/** linguist-generated=true
**/bin/** linguist-generated=true

# File pattern exclusions
*.Designer.vb linguist-generated=true
*.Designer.cs linguist-generated=true
*.g.cs linguist-generated=true
*.g.vb linguist-generated=true
Reference.vb linguist-generated=true
Reference.cs linguist-generated=true
*.min.js linguist-generated=true
*.min.css linguist-generated=true
package-lock.json linguist-generated=true
```

### 2.2 cloc (Count Lines of Code)

[cloc](https://github.com/AlDanial/cloc) supports exclusions:

```bash
cloc --exclude-dir="My Project,Service References,node_modules,vendor,obj,bin" \
     --exclude-content="<auto-generated>|Auto-generated|DO NOT EDIT" \
     --exclude-ext=designer.vb,designer.cs,min.js,min.css \
     /path/to/project
```

**Feature request:** [Issue #396](https://github.com/AlDanial/cloc/issues/396) - Better auto-generated detection

### 2.3 SonarQube

[SonarQube exclusion configuration](https://docs.sonarsource.com/sonarqube/latest/project-administration/analysis-scope/):

```properties
# sonar-project.properties
sonar.exclusions=**/My Project/**,**/Service References/**,**/node_modules/**,**/*.Designer.*,**/Reference.vb,**/Reference.cs

# Exclude from coverage
sonar.coverage.exclusions=**/My Project/**,**/Service References/**,**/*.Designer.*

# Exclude from duplication detection
sonar.cpd.exclusions=**/My Project/**,**/Service References/**,**/*.Designer.*
```

## 3. Analysis Strategy

### 3.1 Analysis Matrix

| Analysis Type | Include Generated? | Rationale |
|---------------|-------------------|-----------|
| **Security Scan** | YES | Proxies can have vulnerabilities |
| **Volume Metrics** | YES (tagged) | LOC counts should reflect reality |
| **Complexity** | NO | Not human-maintainable |
| **Duplication** | NO | Generators produce similar code |
| **Code Smells** | NO | Style issues not actionable |
| **Test Coverage** | NO | Generated code doesn't need tests |
| **Technical Debt** | PARTIAL | Security YES, maintainability NO |

### 3.2 Reporting Strategy

```
IntakeReport
├── summary
│   ├── total_files: 15000
│   ├── total_loc: 2000000
│   ├── generated_files: 200
│   ├── generated_loc: 70000
│   ├── handwritten_files: 14800
│   └── handwritten_loc: 1930000
├── generated_code
│   ├── by_generator_type: [...]
│   ├── by_directory: [...]
│   ├── security_issues: [...]  # Still scanned!
│   └── volume_metrics: {...}
├── quality_metrics  # EXCLUDES generated
│   ├── complexity: {...}
│   ├── duplication: {...}
│   └── maintainability: {...}
└── security  # INCLUDES generated
    ├── all_issues: [...]
    ├── in_generated_code: [...]
    └── in_handwritten_code: [...]
```
