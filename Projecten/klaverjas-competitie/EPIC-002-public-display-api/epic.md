# EPIC-002: Public Display API

## Summary

Readonly API endpoints voor publieke displays en kantine schermen. Toont live standen tijdens competitie-avonden.

## Business Value

- Bezoekers kunnen de live stand volgen op schermen in de kantine
- Geen authenticatie nodig voor weergave
- Automatische refresh voor real-time updates

## Acceptance Criteria

- [ ] Current evening standings endpoint
- [ ] Live match progress endpoint
- [ ] Season standings endpoint
- [ ] No authentication required
- [ ] Optimized for display screens (polling friendly)
