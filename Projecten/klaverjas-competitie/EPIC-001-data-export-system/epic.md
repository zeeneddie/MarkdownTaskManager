# EPIC-001: Data Export System

## Summary

Complete data export functionaliteit voor Excel, CSV en PDF formaten. Dit stelt admins in staat om competitiedata te exporteren voor archivering en rapportage.

## Business Value

- Admins kunnen seizoens- en avondstanden delen met deelnemers
- Data kan worden gearchiveerd voor toekomstige referentie
- Rapportages kunnen worden geprint voor in de kantine

## Acceptance Criteria

- [ ] Evening results export (Excel/CSV)
- [ ] Season standings export (Excel/CSV/PDF)
- [ ] Individual team statistics export
- [ ] Admin audit reports
- [ ] Multiple format support
