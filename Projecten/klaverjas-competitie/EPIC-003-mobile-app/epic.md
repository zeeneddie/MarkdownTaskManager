# EPIC-003: React Native Mobile App

## Summary

Mobile app voor teams om scores in te voeren en standen te bekijken. De kern van het systeem voor dagelijks gebruik door de teams.

## Business Value

- Teams kunnen eenvoudig scores invoeren tijdens de avond
- Geen laptop/PC nodig, werkt op smartphone
- Real-time synchronisatie met backend
- Cross-platform (iOS + Android)

## Acceptance Criteria

- [ ] Team login met wachtwoord wijzigen
- [ ] Score invoer interface met Klaverjas knoppen
- [ ] NAT functionaliteit
- [ ] Roem knoppen (20, 50, 100)
- [ ] Match en game navigatie
- [ ] Standen bekijken
- [ ] Splash screen met kaarten animatie
