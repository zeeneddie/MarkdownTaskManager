## 🔑 KEY DECISIONS MADE

### Architecture
✅ **Dual Database**: PostgreSQL (structure) + ChromaDB (semantics)
✅ **100% Local AI**: Ollama + sentence-transformers (no cloud costs)
✅ **Project-First**: All workflows require active project with BMAD
✅ **BMAD Enforcement**: Green/brown-paper sessions before spec-kit

### Technology Stack
✅ **Backend**: FastAPI + Python 3.11+
✅ **Database**: PostgreSQL 15 + ChromaDB
✅ **Agents**: KaibanJS (TypeScript) + Ollama
✅ **LLMs**: qwen2.5-coder, deepseek-r1, codellama, mistral, qwen2.5
✅ **Testing**: pytest + Jest + Playwright
✅ **Frontend**: Vanilla HTML/CSS/JS (no framework - speed priority)

### Methodology
✅ **Agile Sprints**: 2-week sprints (40 weeks total)
✅ **Test-First**: 100% test coverage maintained
✅ **Weekly Targets**: 1,500-1,800 lines per week
✅ **Overdelivery Pattern**: Averaging 180% of targets
✅ **Documentation**: Inline + weekly summaries
